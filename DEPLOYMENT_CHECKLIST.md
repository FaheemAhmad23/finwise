## Your Deployment Checklist

### Phase 1: Prepare Credentials (15 min)

- [ ] Create Supabase account at [supabase.com](https://supabase.com)
- [ ] Create new project named "finwise"
- [ ] Wait for database to initialize (2-3 minutes)
- [ ] Go to **Settings → Database** and copy connection string
- [ ] Go to **Settings → API** and copy:
  - [ ] Project URL (`https://[project].supabase.co`)
  - [ ] Anon Key (public key)
  - [ ] Service Role Key (secret key)
  - [ ] JWT Secret
- [ ] Generate NEXTAUTH_SECRET: `openssl rand -base64 32`
- [ ] Save all credentials in a safe place (password manager)

### Phase 2: Push to GitHub (5 min)

- [ ] Create GitHub repository
- [ ] Push this code to GitHub
- [ ] Verify code is on GitHub

### Phase 3: Deploy to Vercel (15 min)

- [ ] Go to [vercel.com/new](https://vercel.com/new)
- [ ] Click "Import Git Repository"
- [ ] Select your finwise repository
- [ ] Add environment variables:
  - [ ] DATABASE_URL
  - [ ] POSTGRES_URL
  - [ ] POSTGRES_PRISMA_URL
  - [ ] POSTGRES_URL_NON_POOLING
  - [ ] POSTGRES_USER
  - [ ] POSTGRES_PASSWORD
  - [ ] POSTGRES_HOST
  - [ ] POSTGRES_PORT
  - [ ] POSTGRES_DATABASE
  - [ ] NEXT_PUBLIC_SUPABASE_URL
  - [ ] NEXT_PUBLIC_SUPABASE_ANON_KEY
  - [ ] SUPABASE_SERVICE_ROLE_KEY
  - [ ] SUPABASE_URL
  - [ ] SUPABASE_ANON_KEY
  - [ ] SUPABASE_JWT_SECRET
  - [ ] NEXTAUTH_SECRET
  - [ ] NEXTAUTH_URL
- [ ] Click "Deploy"
- [ ] Wait for build to complete (3-5 minutes)

### Phase 4: Verify Deployment (10 min)

- [ ] Build succeeded (check Vercel dashboard)
- [ ] Open Vercel URL in browser
- [ ] See FinWise login page

## Troubleshooting During Deployment

| If This Happens | Do This |
|---|---|
| Build fails immediately | Check all env vars are added in Vercel Settings → Environment Variables |
| Login page is blank/broken | Open browser console (F12) and check for errors |
| Can't create account | Make sure DATABASE_URL is correct |
| Account created but can't login | Check NEXTAUTH_SECRET and NEXTAUTH_URL are set |
| Login works but no data visible | Check Supabase database tables exist (in SQL Editor) |
| "Connection refused" error | Wait 30 seconds and refresh - Supabase is initializing |
| Build says "MODULE_NOT_FOUND" | Run `pnpm install` locally and verify everything works |

## Quick Reference - Environment Variables

Copy and fill in your values:

```env
# From Supabase - Settings → Database
DATABASE_URL=postgresql://postgres:[PASSWORD]@[PROJECT].supabase.co:5432/postgres
POSTGRES_URL=postgresql://postgres:[PASSWORD]@[PROJECT].supabase.co:5432/postgres
POSTGRES_PRISMA_URL=postgresql://postgres:[PASSWORD]@[PROJECT].supabase.co:5432/postgres
POSTGRES_URL_NON_POOLING=postgresql://postgres:[PASSWORD]@[PROJECT].supabase.co:5432/postgres
POSTGRES_USER=postgres
POSTGRES_PASSWORD=[PASSWORD]
POSTGRES_HOST=[PROJECT].supabase.co
POSTGRES_PORT=5432
POSTGRES_DATABASE=postgres

# From Supabase - Settings → API
NEXT_PUBLIC_SUPABASE_URL=https://[PROJECT].supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=[public_anon_key]
SUPABASE_SERVICE_ROLE_KEY=[service_role_key]
SUPABASE_URL=https://[PROJECT].supabase.co
SUPABASE_ANON_KEY=[public_anon_key]
SUPABASE_JWT_SECRET=[jwt_secret]

# Generated by you
NEXTAUTH_SECRET=[openssl rand -base64 32]
NEXTAUTH_URL=https://your-vercel-url.vercel.app

# Optional - for Google login
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
```
